# mi-portfolio

Portfolio web de Matias Huanaco.

Descripción corta:
> Portfolio web de Matias Huanaco — Estudiante — HTML/CSS/JS — Mobile-first, tema oscuro.

Estructura:
- index.html — Página principal
- styles.css — Estilos
- script.js — JS ligero

Cómo usar:
1. Clona el repositorio:
   - `git clone git@github.com:matiashuanaco-50bit/mi-portfolio.git`
2. Abre `index.html` en un navegador o despliega en Vercel (ver instrucciones en el README).

Despliegue en Vercel:
- Conecta tu cuenta de GitHub a Vercel.
- Importa el repositorio `mi-portfolio`.
- Framework: Static Site / Other (no build command).
- Root directory: `/` (dejalo vacío si los archivos están en la raíz).
- Deploy.
